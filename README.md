Leonida Trophy Guide is an offline tracker and guide for all 55 Grand Theft Auto VI PlayStation 5 trophies — 1 platinum, 2 gold, 6 silver, 46 bronze, 28 hidden until earned. Every trophy is shown with its official name, description and grade as PlayStation publishes them, plus a guide written for this page that cites its sources, a checklist saved in the browser with export and import, filters by kind, a spoiler setting that hides story trophies until they are earned, a seven-stage roadmap to the platinum with the one missable trophy flagged, and a Next-up planner. It runs entirely from its own files, with the network off.

## Run it

```sh
node serve.ts
```
